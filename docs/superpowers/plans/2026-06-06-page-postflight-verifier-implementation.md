# Page Postflight Verifier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `jun-ui verify-page` postflight command that blocks page artifacts or source files that bypass `jun-ui` tokens.

**Architecture:** Keep the verifier inside `scripts/jun-ui.mjs` so target projects can use the installed `jun-ui` CLI. `scripts/validate.mjs` will create temporary passing and failing fixtures to prove strict token validation catches handwritten colors and accepts `var(--jun-ui-*)`.

**Tech Stack:** Node.js ESM, existing `jun-ui` CLI helpers, existing validation smoke tests.

---

### Task 1: Add Verifier Smoke Tests

**Files:**
- Modify: `scripts/validate.mjs`

- [x] **Step 1: Write failing strict-mode tests**

Create a temporary bad artifact with `data-jun-ui-artifact`, relative assets, and CSS containing `#ff0000`. Run `node scripts/jun-ui.mjs verify-page <artifact-dir> --strict` and assert it exits non-zero with a bare-color error.

- [x] **Step 2: Write passing strict-mode tests**

Create a temporary good artifact with the same artifact shape and CSS using `var(--jun-ui-accent)`. Run `node scripts/jun-ui.mjs verify-page <artifact-dir> --strict` and assert it exits zero with a success message.

### Task 2: Implement `jun-ui verify-page`

**Files:**
- Modify: `scripts/jun-ui.mjs`

- [x] **Step 1: Add usage and command routing**

Expose `jun-ui verify-page <config-or-artifact> [--out <dir>] [--strict]`.

- [x] **Step 2: Resolve verification targets**

If the first argument is a directory, treat it as the artifact directory. If it is a config file and `--out` is present, verify the `--out` directory and scan config-declared source files when available.

- [x] **Step 3: Check artifact shape**

Require `index.html`, `data-jun-ui-artifact` or `data-jun-ui-token-console`, relative assets, no `type="module"`, no absolute `href="/..."` or `src="/..."`, and no `href="file://..."` / `src="file://..."`.

- [x] **Step 4: Check Design System usage**

Require `--jun-ui-` token usage in HTML/CSS and fail strict mode on bare colors in source CSS, HTML inline style, and artifact CSS. Allow `tokens.css` and files generated by the token console to define token values.
